# Roadmap

- **Phase 1 — Foundation** ✅ this delivery
- **Phase 2 — Workspace**: multi-file upload, autosave, richer file tree
- **Phase 3 — AI**: real Gemini/Groq wiring end-to-end, SSE token streaming, usage dashboard UI
- **Phase 4 — Repository Intelligence**: indexing pipeline, pgvector embeddings, RAG chat
- **Phase 5 — Coding Agent**: write/edit tools, planning, multi-step execution, approval workflow
- **Phase 6 — Safe Execution**: Docker-sandboxed workers, resource limits, test execution
- **Phase 7 — GitHub**: full OAuth, clone, branches, commits, diffs, pull requests
- **Phase 8 — Production**: monitoring (Prometheus/Grafana/Sentry), rate limiting, S3, AWS deployment
